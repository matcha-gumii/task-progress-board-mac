# Task Progress Board

光沢感のあるMac風UIで、親タスク・子タスク・孫タスクを管理できるmacOS向けデスクトップアプリです。

## 主な機能

- 親・子・孫タスクの作成、編集、進捗管理、兄弟階層内でのドラッグ並べ替え
- 日本語／英語の表示切替
- 小／標準／大の文字サイズ
- グレー、ワイン、ブルー、ブラックのテーマ
- 検索、絞り込み、複製、メモ、Undo／Redo
- アプリ内保存とJSONバックアップ／復元

## 開発起動

```bash
pnpm install
pnpm start
```

## テスト

```bash
pnpm test
```

## macOS配布ビルド

```bash
pnpm run build:mac
```

`.github/workflows/build-mac.yml`を手動実行するか、`v`で始まるタグをプッシュするとApple Silicon版とIntel版を生成できます。

生成物は`dist/`に保存されます。Apple Silicon（arm64）とIntel（x64）に対応します。

現在のビルドはコード署名を行っていません。一般配布する場合は、Apple Developer IDによる署名と公証を追加してください。

タスク本体はアプリ専用のデータ領域に保存されます。設定でJSONバックアップ先を選ぶと、OS標準のファイル選択画面を使って同じデータを自動保存します。表示言語、文字サイズ、テーマ、進捗ゲージの色も設定から変更できます。

## 既存データを移す

以前のHTML版や別のMacから移す場合は、「設定 → JSONをエクスポート」で書き出し、新しい環境の「設定 → JSONをインポート」で読み込んでください。

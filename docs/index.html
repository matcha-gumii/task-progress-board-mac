macOS・Windows用デスクトップアプリ

タスクを、静かに前へ。

親タスクから孫タスクまで、進捗をひとつの画面で整理。光沢感のある落ち着いたデザインで、毎日の作業に集中できます。

Version 1.0.2 ・ macOS / Windows ・ 個人／非商用利用

Mac版の初回起動手順

実際のスクリーンショットを使用しています。ウインドウ外の背景のみを除き、画面内の文字やボタンは加工していません。macOSのバージョンによって表示が異なる場合があります。

  1. DMGを開き、Task Progress BoardをApplicationsフォルダへドラッグします。
  2. Applicationsフォルダに移したTask Progress Boardをダブルクリックします。
  3. Appleの確認警告が表示されたら「完了」を押します。この操作を行うまで「このまま開く」は表示されません。
  4. アップルメニューから「システム設定」＞「プライバシーとセキュリティ」を開きます。アクセシビリティの設定ではありません。
  5. 画面を一番下の「セキュリティ」までスクロールし、Task Progress Boardの「このまま開く」を押します。
  6. 確認画面でもう一度「このまま開く」（または「開く」）を選びます。以後はApplicationsのアイコンから通常どおり起動できます。
v1.0.2ではElectronの署名処理と実行権限の不整合を修正済みです。Apple Developer IDでの署名・公証はまだ行っていないため、上記の初回起動手順が必要です。
Windows版もコード署名されていません。Microsoft Defender SmartScreenの警告が表示された場合は、発行元とダウンロード元を確認したうえで実行してください。

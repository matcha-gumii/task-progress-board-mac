macOS・Windows用デスクトップアプリ

タスクを、静かに前へ。

親タスクから孫タスクまで、進捗をひとつの画面で整理。光沢感のある落ち着いたデザインで、毎日の作業に集中できます。

●Apple Silicon版M1 / M2 / M3 / M4 ●Intel Mac版Intel processor ⊞Windows版Windows 10 / 11 x64

Version 1.0.0 ・ macOS / Windows ・ 個人／非商用利用

TASK PROGRESS BOARD

必要な機能を、すっきり。

複雑な設定を覚えなくても、タスクを追加したその日から使い始められます。

↕

3階層をドラッグ整理

親・子・孫タスクを階層ごとに並べ替え。カードが手についてくる自然な操作感です。

◐

色と文字を自分向けに

4つのテーマ、進捗ゲージの色、3段階の文字サイズを設定できます。

文

日本語と英語に対応

操作画面はいつでも切り替え可能。入力したタスク内容はそのまま保持されます。

Macはメニューの「このMacについて」でチップを確認できます。Windows 10／11の一般的な64bit PCはWindows版を選んでください。

ダウンロード ↓
現在の配布版はApple Developer IDで署名されていません。初回起動時にmacOSの警告が表示された場合は、FinderでアプリをControlキーを押しながらクリックし、「開く」を選択してください。
Windows版もコード署名されていません。Microsoft Defender SmartScreenの警告が表示された場合は、発行元とダウンロード元を確認したうえで実行してください。
